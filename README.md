# gemini-selection

Geminiが適切な選択肢を選びます。
https://gemini-selection.vercel.app/

## アプリ概要

gpt-selection は、複数の選択肢の中から、AI（Google Gemini）があなたの指定した条件に基づいて最適なものを一つ選び出し、その理由とともに提示するアプリケーションです。

プレゼント選び、旅行先の決定、ランチのメニュー選び、アイデアの絞り込みなど、様々な意思決定の場面で、客観的な（あるいは指定したバイアスに基づいた）視点からのアドバイスを得るのに役立ちます。

## 使い方

1.  **選択肢の入力:** 比較したい項目を複数入力します。（例: りんご, バナナ, オレンジ）
2.  **選択タイプの指定:** どのような基準で選んでほしいかを選択します。（例: 健康的なもの, 安いもの, 甘いもの）
3.  **バイアスの入力 (任意):** 特に重視してほしい点を自由記述で入力します。（例: ビタミン C が豊富なもの）
4.  **選択実行:** 「選択」ボタンをクリックすると、AI が最適な選択肢とその理由を表示します。
5.  **結果のコピー:** 表示された結果は、コピーボタンで簡単にクリップボードにコピーできます。
